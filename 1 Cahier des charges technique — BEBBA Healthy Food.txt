Cahier des charges technique — BEBBA Healthy Food

Nom du projet : BEBBA Healthy Food
Slogan officiel : « Vos Plats santé en un clic »
Version : V2 — Refonte complète
Type : plateforme de commande, préparation, livraison et gestion de repas sains
Mode de paiement V1 : paiement à la livraison (COD)
Devise : TND / DT
Zone initiale : Tunisie
Architecture : Web responsive + API + base de données relationnelle
Principe fondamental : commande → cuisine → affectation livreur → livraison → encaissement → suivi/réclamation

17. POSITION GPS

Le navigateur/application du livreur demande l'autorisation GPS.

La position comprend :

longitude

timestamp
heading
speed

Exemple :

{
  "latitude": 35.8,
  "longitude": 10.59,
  "accuracy": 12,
  "heading": 87,
  "speed": 8.2,
  "timestamp": "..."
}
18. FRÉQUENCE GPS

Il ne faut pas envoyer une position toutes les millisecondes.

Le système doit utiliser une logique intelligente :

changement de position significatif ;
intervalle minimum ;
gestion de batterie ;
arrêt automatique à la livraison.

Exemple cible :

5–10 secondes

pendant une livraison active.

La valeur exacte devra être configurable.

19. CONFIDENTIALITÉ GPS

Le client ne doit voir la position du livreur que lorsque :

order_status = delivering

Avant :

ready
waiting_for_driver

→ pas de position GPS publique.

Après :

delivered

→ suivi temps réel arrêté.

20. HISTORIQUE GPS

Le système peut conserver les positions nécessaires à :

analyse ;

statistiques.

Mais il ne faut pas conserver indéfiniment toutes les positions GPS.

Une politique de rétention doit être définie.

Exemple :

historique détaillé : 30 jours

puis suppression/anonymisation selon la politique retenue.
